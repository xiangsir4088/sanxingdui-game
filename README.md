# 一眼三千年 · 三星堆祭司青铜头像

一款基于 HTML5 Canvas 的横向平台跳跃闯关游戏，用 5 个关卡带你走完三星堆祭司青铜头像的一生。

- **主体文物**：三星堆祭司青铜头像（商代，前 1600—前 1046）
- **文化依据**：1986 年四川广汉三星堆二号祭祀坑出土，三星堆博物馆藏；现展于东莞博物馆《吉金万里》特展
- **AI 工具**：TRAE 图像与视频生成、Windows 系统语音合成、FFmpeg 剪辑合成
- **技术栈**：原生 HTML5 Canvas，无框架依赖，键盘 + 手柄双通道，离线可运行

## 玩法

5 关：炉火铸形 → 祭坛之夜 → 深埋千年 → 一九八六·重光 → 展柜对视
每关 3 缕光尘，全部拾起才能走向终点；血量 3 点，被打到本关重来。

## 操作

| 平台 | 移动 | 跳跃 | 开始 | 退出 |
|---|---|---|---|---|
| 键盘 | ← → / WASD | Space / ↑ | Space / Enter | Esc / B |
| 手柄 | 左摇杆 / 十字键 | A | Start | B |

## 运行

双击 `index.html` 即可，无需服务器，无需联网。
